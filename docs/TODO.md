# 待修复事项

需要真实样本验证的事项，等取得对应的订单明细或下载记录，确认实际表现后再修复。已有可复现样本的事项可以先处理。

## 价格统计

| # | 场景 | 问题表现 | 建议处理 | 验证状态 |
|---|---|---|---|---|
| 1 | 自购同一商品的多个规格，例如分别买两个角色包 | 缺少实际订单验证，尚未确认两个规格能否分别识别、计价并正确汇总。 | 按订单行提取变体 ID，每条商品行计价一次，再按商品汇总。重复出现的下载按钮只用于确认 ID。同一规格分两笔购买时，两笔都计入。 | 待真实订单验证 |
| 2 | 同一笔订单送出同一商品的多个规格 | 「ノクア」的两条赠送商品行都没有下载菜单或可提取的变体 ID。快照有两个规格名，现价显示「暂无现价」。 | 逐行查价。缺少 ID 时，用订单行明确的规格后缀在同一商品的 API 规格列表中做唯一匹配，再汇总各行价格。 | 已确认两行分别对应 ¥6,900 和 ¥500，修复后应显示 ¥7,400 |
| 3 | 多规格商品只送出其中一个规格 | 尚未确认单独送出一个规格的订单行是否提供变体 ID。若只提供规格名，现有规则查不到该规格的现价。 | 优先按订单行的变体 ID 查价。缺少 ID 时，只有规格名在该商品下能唯一匹配才取价。 | 待真实订单验证 |
| 4 | 送出单规格商品，订单行没有规格名 | 若订单行也没有变体 ID，现有规则无法查价，即使商品 API 仍提供默认规格的价格。 | 有 ID 时按 ID 查。缺少 ID 时，若订单标题与 API 商品完整标题一致，且 API 仅返回一个无名默认规格，则取该规格的价格。条件不足时保留缺价。 | 购入自用的无名默认规格已验证可按 ID 查价，赠送场景待验证 |

### 金额汇总与明细切换

- [ ] **购买总花费**保留总金额。鼠标悬停时分两行显示「自购商品总花费」和「赠送他人礼物总花费」，均按实际支付金额统计。
- [ ] **当前价格合计**保留自购和送出商品的现价总额。鼠标悬停时分两行显示「自购商品当前价格合计」和「赠送他人礼物当前价格合计」，均按对应规格的当前商店价格统计。
- [ ] 新增独立的**获赠商品当前商店价格合计**，按实际获赠规格的当前商店价格统计。获赠商品只计入这项合计。
- [ ] 明细区提供三个可切换的列表，分别为**购买列表**、**赠送他人列表**和**获赠列表**。购买与赠送他人列表显示实付和现价，获赠列表显示现价。同一商品同时出现在多类记录时，各列表按该类对应的规格独立计价。
- [ ] 各类现价合计只累加已确认的价格，有缺价时标明缺失项，沿用「暂无现价」和「部分现价」的显示规则。

## 下载

- [ ] **自购角色包后补购 Fullset 时处理重复文件。** 不同下载 ID 如果返回同名文件，当前实现可能共用临时路径，后下载的任务也可能覆盖或误归档原角色包的文件。让不同下载 ID 使用独立的临时文件和正式路径，更新时仅归档该 ID 自己的旧文件。同一下载 ID 出现在多个规格中时只下载一次，并保留所属规格。不同下载 ID 的文件经完整 SHA-256 校验一致后，再考虑复用存储。验收覆盖同名并发下载，以及只更新 Fullset 时原角色包仍能正常打开。
